# Organization agent guide

Coding agents and human contributors use the same repository-visible rules.

- Read the target repository `AGENTS.md`, README, authority boundary, and applicable contract or journey before editing.
- State objective, non-goals, starting revision, environment, and evidence class in non-trivial PRs.
- Preserve unrelated work and never commit secrets or personal data.
- Hosted CI and simulation do not prove physical, participatory, accessibility-hardware, RF, power, thermal, or production behavior.
- Models and adapters may propose; identity, consent, policy, storage, and physical-action authorities remain explicit.
- Provide exact validation and a durable recovery/next-action handoff.
